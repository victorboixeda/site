J’aime comprendre comment les choses fonctionnent avant de les raconter. Le marketing réunit ce qui m’anime : créer, analyser, puis prendre la parole pour convaincre. Je veux le faire là où ma curiosité est la plus forte, dans la tech, les sciences et le jeu vidéo. Mes projets montrent comment je m’y prends.
